The PRD has a list view ("Saved searches") but no criterion or flow for its empty state: what an analyst
who has saved nothing sees. The response passes only if it raises this missing empty state as a
**blocking** finding (or with equivalent wording that it must be fixed before approval), and proposes a
criterion or flow for it. Raising it only as advisory, or not at all, fails.
